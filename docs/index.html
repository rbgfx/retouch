Resize, crop, annotate, and compose PNG-centered images from Ruby or the command line. Retouch is pure Ruby and built on Tessel.

Lazy, composable operations

Keep image steps readable

Build a pipeline with chainable transformations. Processing starts only when you render or save the result.

require "retouch"

Retouch.open("screenshot.png")
  .resize("640x")
  .brightness(8)
  .border(1, "#303846")
  .save("small.png")
